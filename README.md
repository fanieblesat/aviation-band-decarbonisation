# aviation-band-decarbonisation

Model, data pipeline and manuscript for:

> **Absorbing sustainable aviation fuel shortfalls in European aviation: a distance-band model of
> corrective action through air traffic management, fleet renewal and alternative supply.**
> Submitted to *Journal of Air Transport Management*, VSI "Green ATM: Tech to Socio-Econ".

The repository reproduces every number, table and figure of the paper from one parameter file.

## What the model does

| Component | File | Paper |
|---|---|---|
| Parameters with source and status (sourced / derived / calibrated / assumption / validation) | `config/parameters.yaml` | Appendix A |
| Flight-level fuel model, calibration to EUROCONTROL shares, validation, regressions | `src/bandmodel/flights.py` | §3.1–3.2, §4.1 |
| Fleet vintage model (generation step, deterioration, retirement, delivery slots) | `src/bandmodel/fleet.py` | §2.4 |
| Well-to-wake band emissions, SAF mandate and supply, scenarios, Shapley attribution | `src/bandmodel/system.py` | §2.1–2.3, §4.2 |
| SAF supply disruption grid and closed-form critical realisation rate | `src/bandmodel/stress.py` | §2.7, §4.3 |
| Minimum-cost corrective LP (ATM, early retirement, alternative SAF) and abatement costs | `src/bandmodel/corrective.py` | §2.8, §4.4 |
| Figures, LaTeX tables and number macros | `src/bandmodel/report.py` | all |

## Reproduce

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python scripts/run_all.py          # writes paper/generated/* and paper/figures/*
python -m pytest -q                # invariants the paper relies on
cd paper && latexmk -pdf main.tex  # builds the manuscript
```

`make all` runs the three steps. The full pipeline takes under a minute.

The manuscript never contains typed numbers: every value in the text is a macro from
`paper/generated/numbers.tex`. To change an assumption, edit `config/parameters.yaml` and re-run.

## Data

* **Synthetic (default).** No open European flight-level inventory with aircraft age and load factor
  exists, so the base-year population is generated by a physically based fuel model and calibrated to
  EUROCONTROL flight and CO₂ shares. It is validated against data not used in the fit (seat-km shares,
  per-passenger intensity pattern, the EUROCONTROL 2050 outlook without fleet renewal).
* **Observed (optional).** Put flights in `data/measured/flights.csv` with the schema in
  `data/measured/README.md` and run `python scripts/run_all.py --measured`. The band statistics and
  regressions are then computed on observations.

## Tests

`tests/test_model.py` checks, among others: the WTW factor; that calibration reproduces its targets and
that the seat-km validation holds; that the index is invariant to the fossil emission factor; SAF
allocation neutrality; the stepwise, minimum-share mandate; that Shapley contributions sum exactly; that
the closed-form critical realisation rate matches a numerical root; and the signs of the load-factor
effects.
